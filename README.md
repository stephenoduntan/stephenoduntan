## 👤 About Me

I am a **Senior Product Designer and Design Team Lead** with over 6 years of experience engineering high-impact digital experiences across **freight logistics, fintech-adjacent platforms, and multi-sided marketplaces**. I lead design strategy and product execution both independently and through my agency, **OOCREATIVs Digital Product Lab**, collaborating with remote teams across the US, Europe, and Nigeria.

I don't stop at static Figma artboards. With a formal background in **mathematics education**, I look at user interfaces as interconnected, constraint-driven systems. I write the **HTML, CSS, JavaScript, and TypeScript** that powers the interface, ensuring that design handoff isn't a game of telephone — it's an engineering-grade blueprint built with clean architecture, accessible markup, and zero-loss visual fidelity.

> 📍 **Current Focus:** Architecting token-driven design systems for data-dense dashboards · Engineering responsive frontend interfaces · Exploring human-computer interaction and civic technology.

## ⚡ The Dual-Discipline Bridge

Most teams face friction at the boundary between design and code. My hybrid workflow eliminates that gap by combining strategic design reasoning with hands-on technical execution:

<table>
<tr>
<td width="50%" valign="top">

### 🎨 Product Design & Design Systems
* **Systematic Token Architecture:** Organizing typography, color scales, spacing, and elevation with Figma variables and semantic alias tokens.
* **Complex Dashboard & Workflow Design:** Translating complicated logistical, financial, and operational states into intuitive user interfaces.
* **Component Libraries & Variants:** Engineering robust component sets with variants, auto-layout, boolean properties, and responsive constraints.
* **Zero-Loss Developer Handoff:** Writing exhaustive documentation with edge cases, hover/active states, and spacing formulas that engineers appreciate.
* **Design Team Mentorship:** Leading design reviews, establishing standards, and aligning multidisciplinary teams around product goals.

</td>
<td width="50%" valign="top">

### 💻 Frontend Engineering & Web Craft
* **Semantic & Accessible Markup:** Structuring clean, accessible HTML5 landmarks and ARIA roles adhering to WCAG 2.1 AA standards.
* **Modern Responsive Styling:** Crafting fluid, responsive layouts using modern CSS Grid, Flexbox, custom properties, and Tailwind CSS.
* **Interactive UI & Scripting:** Building modular client-side behavior with modern JavaScript (ES6+), TypeScript, and component-driven logic.
* **Performance & Core Web Vitals:** Optimizing asset delivery, rendering pathways, and typography for speed and smoothness.
* **Audit & Heuristic Remediation:** Converting UX audit findings directly into validated, production-ready frontend code fixes.

</td>

## 🔬 How I Ship: Design-to-Code Pipeline

From initial constraints to living production code, every project moves through a structured, transparent 5-stage lifecycle:

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  01. DISCOVER│ ──> │  02. STRUCTURE│ ──> │  03. CRAFT   │ ──> │  04. BUILD   │ ──> │  05. AUDIT   │
│ Constraints  │     │ IA & Tokens  │     │ Figma System │     │ Code & Logic │     │ QA & Handoff │
└──────────────┘     └──────────────┘     └──────────────┘     └──────────────┘     └──────────────┘
```

1. **Discover & Align:** Map business drivers, technical limitations, user journeys, and legacy constraints *before* opening Figma.
2. **Structure & Tokenize:** Establish information architecture, site maps, layout grids, typography scales, and token taxonomies.
3. **Design the System:** Build in Figma using real content, scalable auto-layout, multi-state component variants, and strict variable bindings.
4. **Implement in Code:** Translate Figma components into clean, semantic, accessible HTML5/CSS3/TypeScript with fluid responsiveness.
5. **Audit & Hand Off:** Validate against WCAG 2.1 AA, verify cross-browser performance, and deliver living specs developers can actually build with.
